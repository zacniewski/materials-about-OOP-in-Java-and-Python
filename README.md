# Materials about OOP in Java and Python

Wstęp do programowania zorientowanego obiektowo z wykorzystaniem języków Java i Python.

## Cel repozytorium

Repozytorium porządkuje komplet materiałów do nauki OOP w dwóch ekosystemach:
- **Java** - ścieżka bardziej formalna, klasowa i silniej oparta na typach,
- **Python** - ścieżka wieloparadygmatowa, bardziej elastyczna i oparta o konwencje, duck typing oraz praktykę projektową.

Celem jest równoległe pokazanie:
- wspólnych fundamentów OOP,
- różnic językowych i projektowych,
- praktyki laboratoryjnej dopasowanej do obu środowisk.

## Efekty uczenia

Po przerobieniu materiału student powinien:
- rozumieć model obiektowy w Javie i Pythonie,
- projektować klasy, interfejsy, protokoły i relacje między obiektami,
- stosować enkapsulację, dziedziczenie, polimorfizm i kompozycję,
- znać idiomy obu ekosystemów: `property`, `dataclass`, `Protocol`, `pytest`, `venv` w Pythonie oraz klasyczną strukturę OOP, biblioteki standardowe, wyjątki i testowanie w Javie,
- rozumieć podstawy SOLID i ich praktyczne zastosowanie w obu językach.

## Proponowana kolejność realizacji

1. Najpierw przejście wykład + laboratorium w jednym języku od modułu 1 do 15.
2. Następnie porównanie analogicznych tematów Java vs Python, szczególnie dla modułów 4-15.
3. Szczególną uwagę warto zwrócić na różnice:
   - Java: interfejsy, klasy abstrakcyjne, silniejsze formalne typowanie,
   - Python: `property`, `dataclass`, `Protocol`, duck typing, `pytest`, mutowalność i model importów.

## Uwagi organizacyjne

- Repozytorium zawiera obecnie **60 plików Markdown** materiałów dydaktycznych: 15 wykładów i 15 laboratoriów dla Javy oraz 15 wykładów i 15 laboratoriów dla Pythona.
- Ścieżki Java i Python mają celowo podobną numerację, aby można było łatwo porównywać te same tematy między językami.
- Dodatkowe PDF-y i materiały pomocnicze w folderach językowych zostały pozostawione jako uzupełnienie, ale głównym torem nauki są pliki Markdown wskazane powyżej.
